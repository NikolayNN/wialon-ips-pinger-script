# Проверка Wialon IPS через PowerShell

## Цель и границы

Один скрипт `Test-WialonIps.ps1` для быстрой ручной проверки TCP-порта Wialon IPS: подключение, логин L с успешным ответом AL, затем ping P с ответом AP. Поддерживаются IPS 1.1 и 2.2. Передачи координат, UDP, TLS, повторяющегося ping и графического интерфейса нет.

## Запуск и ввод

Скрипт работает в штатном Windows PowerShell 5.1 без сторонних модулей. Файл с русским текстом сохраняется в UTF-8 с BOM для совместимости с 5.1.

Параметры: `Server`, `Port`, `Imei`, `Protocol`, `Password`, `TimeoutSeconds`. Недостающие адрес, порт, IMEI и версию скрипт запрашивает интерактивно. При интерактивном запуске запрашивается также необязательный пароль со скрытым вводом; пустой ввод означает отсутствие пароля. При полностью заданных обязательных параметрах пароль по умолчанию отсутствует и дополнительных запросов нет. Таймаут по умолчанию — 5 секунд.

Адрес не должен быть пустым и передаётся без схемы URL. Порт — целое число от 1 до 65535. IMEI принимается строкой из 15 десятичных цифр с сохранением начальных нулей. Версии — только `1.1` и `2.2`. Пароль не должен содержать разделители протокола или переводы строк. Ошибочный интерактивный ввод можно исправить повторным вводом; ошибочные явно заданные параметры завершают запуск с понятным сообщением.

## Обмен

1. Установить TCP-соединение с ограничением времени подключения, включая разрешение доменного имени.
2. Сформировать L выбранной версии и отправить ASCII-пакет с окончанием CRLF. Формат версии 2.2, значение поля версии и область вычисления CRC сверяются с официальной спецификацией Wialon перед реализацией.
3. Прочитать полный ответ до CRLF и проверить `#AL#1`. Отрицательный AL, неожиданный пакет, закрытие соединения и таймаут означают ошибку логина; P после них не отправляется.
4. В том же соединении отправить `#P#\r\n` и проверить `#AP#\r\n`.
5. Закрыть соединение при любом исходе. Код завершения — 0 при полном успехе, ненулевой при ошибке.

Чтение учитывает разбиение ответа на несколько TCP-фрагментов и сохраняет уже прочитанные байты следующего пакета. Каждый ожидаемый ответ имеет общий таймаут, который не продлевается каждым новым фрагментом. Размер строки ответа ограничен, чтобы некорректный сервер не заставлял бесконечно накапливать данные.

## Вывод и ошибки

В консоли видны этапы подключения, отправленные пакеты и ответы с явным отображением CRLF. В отправленном L пароль скрыт. Диагностика различает ошибку подключения, отказ авторизации, ошибку CRC по ответу сервера, неожиданный ответ, закрытие соединения и таймаут. Итог подтверждает только успешный обмен L/AL и P/AP с указанным сервером и IMEI.

## Файлы и проверка

Поставляются скрипт и README на русском с интерактивным запуском, примером запуска с параметрами и командой для разового запуска при ограничении ExecutionPolicy. Настройки безопасности Windows глобально не меняются.

Локальные проверки используют TCP-сервер на loopback и стандартные средства PowerShell/.NET без сторонних библиотек: успешный обмен для обеих версий, проверка фактического содержимого L и CRC по контрольному примеру спецификации, фрагментированные ответы, отказ AL без последующего P, неожиданный ответ, закрытие соединения и таймаут. Проверка на реальном сервере требует его адреса, порта и зарегистрированного IMEI и не входит в локальную проверку.
