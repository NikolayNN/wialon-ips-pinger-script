# Проверка Wialon IPS

Утилита для Windows PowerShell **5.1 или новее**, без установки модулей. Проверяет TCP-подключение, логин трекера (`L → AL`) и ping (`P → AP`) для Wialon IPS **1.1** и **2.2**. После одной проверки отключается.

## Запуск с окном

Дважды щёлкните **`Запустить.cmd`** в папке проекта. Установка программ и права администратора не нужны; файлы `WialonIps.Gui.ps1` и `Test-WialonIps.ps1` должны лежать рядом с ним.

1. Введите IP/домен сервера, порт и IMEI трекера.
2. Выберите версию IPS; при необходимости укажите пароль и таймаут.
3. Нажмите **«Проверить»**. В окне появятся результаты подключения, авторизации и ping, а ниже — обмен пакетами.
4. Кнопка **«Скопировать журнал»** копирует журнал без пароля, чтобы передать результат специалисту.

Во время проверки окно остаётся отзывчивым. Чтобы повторить проверку, измените данные и снова нажмите «Проверить». Закрытие окна прерывает текущую проверку. Введённые значения не сохраняются на диск.

Запуск окна вручную:

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\WialonIps.Gui.ps1
```

## Запуск в консоли

Откройте PowerShell в папке скрипта:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test-WialonIps.ps1
```

Введите IP или домен без `http://`, порт, 15 цифр IMEI и версию (`1.1` или `2.2`). При запросе пароля нажмите Enter, если пароля нет. Ввод пароля скрыт.

`ExecutionPolicy Bypass` действует только в запущенном процессе. Глобальные настройки Windows не меняются.

## Запуск с параметрами

```powershell
.\Test-WialonIps.ps1 -Server example.org -Port 20332 -Imei 012345678901234 -Protocol 2.2
```

Если политика Windows блокирует запуск, передайте те же параметры после `-File` в команде запуска в консоли.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Test-WialonIps.ps1 -Server 192.0.2.10 -Port 20332 -Imei 012345678901234 -Protocol 1.1 -TimeoutSeconds 10
```

Адреса в примерах нужно заменить своим сервером. Если обязательные параметры заданы полностью, скрипт не задаёт вопросов и использует отсутствие пароля по умолчанию. Необязательный параметр `-Password` задаёт пароль трекера; для скрытого ввода пароля используйте интерактивный запуск, поскольку аргументы командной строки могут сохраняться в истории.

| Параметр | Значение |
| --- | --- |
| `Server` | IPv4, IPv6 или доменное имя |
| `Port` | TCP-порт, 1–65535 |
| `Imei` | Ровно 15 цифр; начальные нули сохраняются |
| `Protocol` | `1.1` или `2.2` |
| `Password` | Необязательный ASCII-пароль без `;`, `#` и управляющих символов |
| `TimeoutSeconds` | 1–300 секунд; по умолчанию 5 |

## Результат

Пример успешного обмена IPS 1.1 без пароля:

```text
Подключение к 127.0.0.1:20332 (Wialon IPS 1.1)...
TCP: подключено.
Авторизация трекера...
TX: #L#012345678901234;NA\r\n
RX: #AL#1\r\n
Логин: принят.
Проверка ping...
TX: #P#\r\n
RX: #AP#\r\n
Ping: ответ получен.
Проверка пройдена: L/AL и P/AP подтверждены.
```

`\r\n` в выводе обозначает реальные байты CRLF на проводе. Пароль в выводе скрывается.

Код завершения **0** — обе проверки успешны; **1** — ошибка ввода, подключения, логина или ping. После запуска через `powershell.exe` код доступен в `$LASTEXITCODE`.

Таймаут ограничивает подключение (включая DNS) и ожидание каждого полного ответа отдельно. Отказ логина останавливает проверку до отправки ping. Скрипт различает отклонение соединения (`AL 0`), неверный пароль (`AL 01`), неверную CRC (`AL 10`), неожиданный ответ, разрыв соединения и таймаут.

IMEI должен быть зарегистрирован на сервере, если сервер требует этого для авторизации. Успешное TCP-подключение само по себе ещё не подтверждает поддержку Wialon IPS; полный успех означает ответы на L и P для указанного IMEI. Проверка не отправляет координаты.

## Форматы протокола

- IPS 1.1: `#L#IMEI;Password\r\n`.
- IPS 2.2: `#L#2.0;IMEI;Password;CRC16\r\n`. Значение **2.0** в поле версии L прямо указано в документации **2.2**. CRC-16/ARC вычисляется по `2.0;IMEI;Password;`, включая последний `;`, и передаётся четырьмя HEX-цифрами.
- При отсутствии пароля передаётся `NA`. Для обеих версий ping — `#P#\r\n`, ответ — `#AP#\r\n`.

Источники: [официальная спецификация IPS 1.1](https://extapi.wialon.com/hw/cfg/Wialon%20IPS_en.pdf), [официальная спецификация IPS 2.2](https://wialon.com/hw/files/Wialon%20IPS%20v.2.2%20%28EN%29.pdf).

## Проверка разработки

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-WialonIps.Tests.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\Test-WialonIps.Gui.Tests.ps1
```

Проверки запускают сервер только на loopback и используют стандартные средства PowerShell/.NET. Внешний сервер не требуется. Ключ `-PacketsOnly` запускает только проверки формирования пакетов и CRC.

При редактировании сохраняйте `.ps1` в **UTF-8 с BOM**: Windows PowerShell 5.1 иначе может неверно прочитать русские строки.
